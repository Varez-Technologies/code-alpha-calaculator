# CodeAlpha - Scientific & Standard Calculator

A responsive, feature-rich web calculator built with HTML, Tailwind CSS, and JavaScript as part of the **CodeAlpha Frontend Internship**.

## 🚀 Features

- **Dual Modes:** Standard arithmetic calculations and advanced scientific operations (Trigonometry: sin, cos, tan; Logarithms: ln, log; Powers & Roots: x², √, xʸ; Constants: π, e).
- **Interactive History Tape:** View, review, and recall previous calculations.
- **Angle Units:** Toggle between Degree (DEG) and Radian (RAD) modes for trigonometric calculations.
- **Keyboard Support:** Complete keyboard navigation and shortcuts for fast calculations.
- **Responsive Design:** Clean, modern physical-inspired layout optimized for both desktop and mobile screens.

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure
- **Tailwind CSS:** Modern utility-first styling with custom tactile design
- **JavaScript (ES6+):** Pure vanilla JavaScript for state management, precision math, and event handling

## 💻 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Varez-Technologies/code-alpha-calaculator.git
   ```
2. Navigate to the project directory:
   ```bash
   cd code-alpha-calaculator
   ```
3. Open `index.html` directly in any modern web browser.
